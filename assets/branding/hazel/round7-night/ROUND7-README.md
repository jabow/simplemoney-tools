# Hazel — round 7 "cute but professional" (26 September 2026)

James rejected the round-6 silhouettes ("look odd"): the character should stay cute, and a
darker ground should do the professional work. This set is the round-5 character (face kept,
head and eye slightly smaller) on night navy, holding a larger coin so the £ stays legible at
40 px (£ cap height 80 on the 512 grid ≈ 6 px at 40 px), with a knockout ring of ground colour
around the coin so it separates from the body at small sizes.
