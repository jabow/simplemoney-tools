# Simple Money Tools — Squirrel mark

Asset set cut from the "The Squirrel" concept round (15 September 2026).
**Status: candidate, not yet adopted.** The live site still uses the Medallion
mark in `assets/branding/logo-medallion*`.

## Held-object variants (full figure, 96×96 viewBox)

| File | Object | Note |
|---|---|---|
| `logo-squirrel-coin.svg` | Plain coin | **Recommended.** Rim, inner ring and highlight — reads as money at 20 px. |
| `logo-squirrel-gbp.svg` | Pound coin | Unambiguous, but signals UK-only. |
| `logo-squirrel-acorn.svg` | Acorn | Most natural for a squirrel; says nothing about money on its own. |
| `logo-squirrel-acorn-coin.svg` | Acorn coin | Hybrid — most distinctive, fiddliest at small sizes. |
| `logo-squirrel-chart-coin.svg` | Chart coin | Carries the existing rising-line mark onto the coin. |
| `logo-squirrel-bitcoin.svg` | Bitcoin | Moves the brand into the crypto category — see the caveat in the concept doc. |

## Crops

| File | Use |
|---|---|
| `logo-squirrel-face.svg` | Face only, transparent — for tiny sizes. |
| `logo-squirrel-face-disc.svg` | Face on a deep-green disc — favicon / avatar. |
| `logo-squirrel-badge.svg` | Full figure on a cream disc — social avatar, stickers. |
| `logo-squirrel-tile.svg` | Full figure on a green rounded square — app / extension tile. |

## PNGs

- `logo-squirrel-coin-{32,48,128,180,256,512}.png` — full figure
- `logo-squirrel-face-disc-{16,32,48,128,180,512}.png` — favicon set
- `logo-squirrel-tile-{128,512}.png` — extension / store tile
- `logo-squirrel-{gbp,acorn,acorn-coin,chart-coin,bitcoin}-512.png` — variant previews

Below ~24 px the full figure loses its detail; use the face-disc set instead.
