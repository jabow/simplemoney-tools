Privacy Policy

How simplemoney-tools.co.uk and the free tools linked from it handle information.

Draft version — last updated 25 August 2026. Not yet reviewed by a solicitor.

This page is a placeholder, not legal advice. It's written to be cautious and honest about what this site currently does, but it has not been reviewed by a qualified solicitor. Have this reviewed before relying on it, especially once Simple Money Tools Pro (which will handle a read-only connection to a third-party financial account) launches.

This website

This website (simplemoney-tools.co.uk) is a static set of pages with no user accounts and no server-side database. The contact form and "register interest" forms on this site are currently placeholders — see the notice on the contact page. Until a form service or backend is connected, submitting them does not send or store any personal data.

If analytics or a working contact/newsletter service is added in future, this section will be updated to name the specific service(s) used and what they collect.

The free Budget Tracker

The Budget Tracker is a downloadable Excel file. Once downloaded, it runs entirely on your own device — Simple Money Tools does not receive the figures you enter into it.

The Personal Dashboard Chrome extension (free)

Personal Dashboard is designed to run locally in your browser. Bookmarks, watchlist tickers and settings are stored using Chrome's local extension storage on your device. Live data such as weather and crypto/stock prices is fetched from third-party providers as needed to display it; Simple Money Tools does not operate its own server that logs this activity.

Simple Money Tools Pro (in development)

Pro is not yet released. When it launches, any optional integration (such as Trading 212) will be read-only, opt-in, and documented in detail in its own setup guide before you connect anything. This policy will be updated with specifics — what's requested, what's shown, and what's never collected — before Pro becomes available, not after.

What we don't do

  • We do not sell personal data.
  • We do not request full account credentials for any integration — only official, read-only API access where offered.
  • We do not display fabricated figures where real data is unavailable — an unavailable metric is shown as unavailable, not guessed.

Cookies

This static site does not currently set its own cookies. If analytics is added later, this section will list exactly what's used and how to opt out.

Your rights

Under UK GDPR, you have rights to access, correct or delete personal data held about you. Since this site does not yet store personal data beyond what your own browser holds locally, there is currently little to request — this will be expanded once any real data collection (e.g. a working contact form or Pro account system) is added.

Contact

Questions about this policy can be sent via the contact page.
